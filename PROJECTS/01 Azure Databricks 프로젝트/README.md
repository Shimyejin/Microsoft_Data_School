# 🎵 MUPIC: 이미지 기반 음원 추천 시스템

> 감정을 담은 이미지를 업로드하면, 당신에게 맞는 음악을 추천해드립니다.

## 📌 프로젝트 개요

**MUPIC**은 사용자가 업로드한 이미지를 바탕으로 감정을 분석하고, 적절한 음악을 추천하는 콘텐츠 기반 추천 시스템입니다. 시청각 결합 콘텐츠 소비가 증가하는 시대에, 감성에 맞춘 음악 추천을 통해 사용자 경험을 극대화하는 서비스를 목표로 합니다.

## 🧠 주요 기능 및 로직

### 1. 데이터 수집 및 전처리
- **Genie**에서 16개 장르의 플레이리스트 크롤링
- 곡명, 아티스트, 장르, 해시태그 정보 수집
- 태그는 총 6가지 카테고리로 분류: `상황`, `감성`, `시간대`, `스타일`, `날씨`, `계절`
- 중복 및 결측값 제거 → 약 12만 곡

### 2. 태그 임베딩
- 곡별 태그를 문장으로 합쳐 **SentenceTransformer**로 384차원 임베딩
- 사용자 이미지 또한 GPT 기반 텍스트 변환 후 동일 방식으로 임베딩

### 3. 추천 시스템
- 사용자 임베딩과 각 곡의 임베딩 간 코사인 유사도 계산
- 선택한 장르별로 유사도 가장 높은 곡 1개 + 무작위 2곡 추천 → 총 5곡

### 4. 시스템 자동화
- **Databricks Jobs API**를 통해 노트북 자동 실행
- Flask에서 Databricks Job 호출 → 추천 로직 실행

### 5. 웹 서비스 구현
- 사용자 인터페이스 구성:
  - `Home`: 이미지 업로드 및 장르 선택
  - `Loading`: 분석 중 화면
  - `Recommendation`: 추천 결과 + YouTube 실시간 재생
  - `Archive`: 모든 사용자 이미지 및 추천 이력 공유

---

## 🧾 데이터베이스 구조 (PostgreSQL)

- `images`: 이미지 정보
- `image_tags`: 이미지 기반 GPT 추출 태그 저장
- `recommendations`: 추천된 음악 정보 저장 (곡명, 아티스트, 유사도, 장르 등)

---

## 📽 시연 흐름

1. 사용자가 이미지 업로드 및 장르 선택
2. GPT API → 이미지에서 텍스트 태그 추출
3. Databricks Job → 추천 시스템 실행
4. 유사도 계산 및 추천 음악 선정
5. 추천 결과를 웹에서 확인 및 청취 (YouTube API)
6. 추천 내역은 DB에 자동 저장 → Archive 공유 가능

## 💡 프로젝트 차별점

- **GPT 기반 감성 태깅** + **콘텐츠 유사도 기반 추천**

- 사용자의 이미지와 음악 이력을 공유할 수 있는 **Archive 기능**
