    df_cleaned = dataframe1[nan_ratio_per_row < rate]
    return df_cleaned,

# Execute Python Script 2: 0이 많은 열 제거
def azureml_main(dataframe1 = None, dataframe2 = None):
    rate = 0.7
    zero_ratio_cols = (dataframe1 == 0).mean()
    df_cleaned = dataframe1.drop(columns = zero_ratio_cols[zero_ratio_cols >= rate].index)
    return df_cleaned,

- K-means, 신경망 등 값의 범위 중요할 때

- 0~1 사이 확률형태로 변환하고 싶을 때

- 극단적인 이상치, 오른쪽 꼬리가 긴 분포에서 사용

- 분포를 [-1, 1]로 제한하고 싶을 때 (신경망 입력 등)
