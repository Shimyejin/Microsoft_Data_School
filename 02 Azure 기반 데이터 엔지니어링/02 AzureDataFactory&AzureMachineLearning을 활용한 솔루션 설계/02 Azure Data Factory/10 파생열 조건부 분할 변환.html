파생열 조건부 분할 변환

⚙️ 파생열 변환 (Derived Column Transformation)

  • 기존 컬럼을 가공하거나 새로운 컬럼 생성
  • 수식이나 조건식을 활용해 새로운 정보를 추출하거나 결측값 보완 가능
  • 특징
    • 원본 소스 변경 없이 컬럼 가공
    • 다양한 수치/문자/날짜 함수 사용 가능
    • 실시간 미리보기로 결과 확인
  • 예시
    목적예시
    결측값 처리address == null → '미기입'
    새로운 컬럼 생성salary_grade: salary < 300 → 'Low', email_domain: split(email, '@')[1]
    기존 컬럼 변경country → upper(country)
    계산식 삽입salary × workdays → total_wage

⚙️ 조건부 분할 변환 (Conditional Split Transformation)

  • 한 행의 데이터를 지정 조건에 따라 여러 흐름으로 분기
  • 조건은 순차적으로 평가, 처음으로 참이 되는 조건에만 분기
  • 특징
    • 시각적으로 로직 분기 가능
    • 기본 분기(Default output) 설정 가능
    • 다양한 조건 결합 가능 (salary > 400, country == 'KOR' 등)
  • 예시
    조건분기 처리
    salary > 400고소득자 처리
    country == 'KOR'국내 → Sink1
    그 외해외 → Sink2

파생열 변환은 데이터를 가공/보완하여 새로운 정보를 만들고,

조건부 분할 변환은 데이터를 조건에 따라 다중 경로로 나누는 기능입니다.

→ 두 변환을 결합하면 데이터 정제 + 라우팅 자동화가 가능해집니다.

[Source: employee.csv]
          ↓
[Derived Column]
  - address가 null이면 '미기입'
  - salary가 null이면 0
  - country는 대문자로 변환
  - salary_grade 컬럼 생성
  - email_domain 컬럼 추출
          ↓
[Conditional Split]
  - 조건: country == 'KOR' → 본사
  - 나머지 → 해외지사
        ↓            ↓
 [Sink: headquarters-employee.csv]
 [Sink: branch-employee.csv]
