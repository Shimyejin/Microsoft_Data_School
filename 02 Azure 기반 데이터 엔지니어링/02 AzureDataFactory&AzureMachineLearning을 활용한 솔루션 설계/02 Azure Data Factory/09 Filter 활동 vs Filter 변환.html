Filter 활동 vs Filter 변환

구분Filter 활동Filter 변환
위치파이프라인(Activity)매핑 데이터 플로우(Transformation)
대상배열 (Array, JSON 등)테이블 데이터 (행/열 기반)
조건파이프라인 표현식 사용 (@item().name)데이터 플로우 식 사용
용도파일/테이블 목록 등 구조화된 리스트 필터링컬럼 조건으로 행 추출
예시.csv 확장자만 선택income == '>50K' 조건 행 추출
  • JSON, 배열, 파일 목록 등 리스트 데이터를 조건으로 걸러냄
  • 주로 Get Metadata, Lookup 결과와 함께 사용

🧪 실습 구성 요약

  • 목표: 특정 확장자(.csv) 파일만 처리
    • Get Metadata
      • Blob 폴더 내 파일 목록을 배열로 조회
      • childItems로 리스트 수집
    • Filter 활동
      • 조건: @endswith(item().name, '.csv')
      • .csv 파일만 걸러냄
    • ForEach 활동
      • 필터된 .csv 파일 리스트를 반복하여 복사 수행
    • (옵션) If Condition
      • 컨테이너 존재 여부 등 분기 처리 가능

⚙️ 파라미터 & 표현식 예시

항목예시
필터 조건@endswith(item().name, '.csv')
반복 대상@activity('FilterActivity1').output.value
파일 이름 참조@item().name

[Get Metadata]
   ↓
[Filter (endswith '.csv')]
   ↓
[ForEach]
   └─ Copy 각 파일
  • 필요할 경우 child pipeline을 만들어 파일 이름을 매개변수로 전달하여 재사용 가능.
