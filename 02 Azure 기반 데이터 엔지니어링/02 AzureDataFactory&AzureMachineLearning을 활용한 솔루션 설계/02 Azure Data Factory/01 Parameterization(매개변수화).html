Parameterization(매개변수화)

  • 값을 동적으로 받아 재사용성과 유연성을 높이는 기법
  • 다양한 구성요소에서 사용 가능:
    • Parameters: 실행 전 외부에서 입력
    • Variables: 실행 중 내부 상태 저장
    • Expressions: 동적 값 계산 (조건, 날짜, 문자열 등)

Parameters

  • 외부 입력값을 파이프라인/데이터세트 등에 전달
  • 주로 정적인 실행 값
@pipeline().parameters.inputDate
목적설명
날짜별 실행특정 일자 데이터 처리
환경 분기Dev/Prod 선택 자동화
SQL 동적 실행부서별 쿼리 등 구성

Variables

  • 파이프라인 내에서 생성·변경 가능한 내부 변수
  • 동적 로직 제어, 상태 저장 가능
"variables": {
  "retryCount": { "type": "Int", "defaultValue": 0 }
}
@add(variables('retryCount'), 1)

Expressions

  • 런타임 시 동적 계산/조건 처리를 위한 표현식
  • 주요 함수
    • concat, formatDateTime, addDays, if, length, json
@concat('backup/', pipeline().parameters.region, '/', formatDateTime(utcNow(), 'yyyyMMdd'))

📌 [비교] Parameter vs Variable

항목ParameterVariable
정의실행 시 외부 입력값실행 중 내부 값 저장
변경 가능성불가가능 (Set Variable로 변경)
활용날짜 필터링, 환경 설정 등재시도 카운터, 중간 값 저장 등
참조@pipeline().parameters.name@variables('name')

🧪 실습 흐름 요약

데이터세트 매개변수화

  1. 데이터세트에서 fileName 및 tableName 등을 매개변수화
  1. 동적 콘텐츠를 통해 파일 경로/테이블 이름 지정
  1. Copy Activity에서 매개변수 전달 후 디버그 실행

활용 예시

  • penguins.csv → penguins-export.csv로 백업
  • 파일 이름에 날짜 붙이기:
    @concat('penguins-', formatDateTime(utcNow(), 'yyyyMMdd'), '.csv')
