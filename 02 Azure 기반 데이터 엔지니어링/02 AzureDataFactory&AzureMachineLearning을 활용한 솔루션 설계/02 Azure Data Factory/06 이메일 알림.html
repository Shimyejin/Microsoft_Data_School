이메일 알림

✅ 1. 이메일 알림 개요 및 필요성

  • 목적: ADF 실행 결과(성공/실패 등)를 운영자에게 이메일로 자동 알림
  • 필요 이유:
    • 파이프라인 자동 실행 시 처리 상태 확인이 어려움
    • 이상 발생 시 즉각 대응 가능
    • 운영 효율성과 시스템 신뢰성 향상

✅ 2. 이메일 알림 주요 사례

분류사례설명
개발/운영ETL 오류 알림운영팀에 오류 상황 실시간 전달
보안/감사민감정보 처리 알림감사 목적 로그 남김
분석데이터 수집 시작 알림자동화된 분석 시점 확인
보고서Power BI 리프레시 알림사용자에게 최신 리포트 반영 시점 알림

✅ 3. 이메일 알림 구현 방식

방식설명장점권장 시나리오
Azure Monitor AlertsADF 실행 상태(성공/실패 등)를 기반으로 자동 알림설정 간단, 추가비용 없음단순 성공/실패 감지
Web Activity + Logic AppsADF 내 Web 활동으로 Logic App 호출 → 이메일 발송커스터마이징 가능, HTML 사용 가능맞춤형 알림, 제목/내용 설정 등

✅ 4. Azure Monitor Alerts 방식

  • 기능: ADF 활동 결과 기반 Metric을 조건으로 설정하여 Alert 트리거
  • 특징:
    • 이메일, SMS, Logic Apps 등 다양한 알림 채널 지원
    • 저비용, 간단 설정
    • 포맷 및 내용 커스터마이징은 어려움
    • 실시간성은 다소 제한

✅ 5. Web Activity + Logic Apps 방식

  • 구성: ADF의 Web Activity → Logic App HTTP 트리거 호출 → 이메일 발송
  • 장점:
    • HTML 기반 이메일 가능 (가독성 높음)
    • 제목/본문/수신자 등을 ADF 변수로 설정 가능
    • 다양한 분기 로직 구현 가능
  • 활용 예:
    • 특정 Activity 실패 시 맞춤 메시지 포함
    • 실행 ID, 시간, 파이프라인 이름 포함 가능

✅ 6. 실습 구성 요약

💡 실습 1: Azure Monitor 알림 구성

  1. ADF 파이프라인 실행 상태 Metric 선택
  1. Alert Rule 생성
  1. 이메일 액션 그룹 설정
  1. 트리거 조건 만족 시 알림 전송 테스트

💡 실습 2: Logic App 기반 알림 구성

  1. ADF에서 Web Activity 추가
  1. Logic App 생성 (HTTP Request → Email 전송)
  1. 트리거 URL ADF에 설정
  1. 파라미터로 메시지 본문, 제목, 실행ID, 시간 등 전달
  1. 실패 시 메시지 예시:
"message": "@{activity('Execute Pipeline1').error.message}"
  1. HTML 포맷 설정으로 가독성 향상
  1. 마스터 파이프라인 내 연결 및 테스트 수행

✅ 7. 요약

  • ADF의 이메일 알림은 Azure Monitor 또는 Logic Apps 방식으로 구성 가능
  • 단순 알림은 Monitor로 충분, 맞춤 알림은 Logic Apps가 적합
  • 실습을 통해 각각의 구성 방법, 장단점, 메시지 처리 방법 등을 학습함
  • 운영 효율화, 에러 대응 자동화에 효과적
