필터(Filter) & 정렬(Sort) 변환

⚙️ 필터 변환 (Filter Transformation)

항목설명
정의지정한 조건을 만족하는 행(row)만 선택
조건식 예시Score > 80, Category == 'A' and Region != 'Seoul'
미리보기필터 결과 즉시 확인 가능
활용 예시고득점 학생만 추출, 결측값 제거, 완료된 주문만 처리 등
장점불필요한 데이터 사전 제거로 성능 향상, 로직 시각화

⚙️ 정렬 변환 (Sort Transformation)

항목설명
정의하나 이상의 컬럼 기준으로 오름차순/내림차순 정렬
정렬 기준컬럼 여러 개 지정 가능 (우선순위 적용)
정렬 순서Ascending (오름차순), Descending (내림차순)
미리보기정렬 결과 즉시 확인 가능
활용 예시상위 10명 정렬, 거래일 최신순, 복합 기준 정렬 등
