증분 데이터 로드

✅ 1. 개요: 증분 데이터 로드란?

  • 증분 데이터 로드(Incremental Load): 전체 데이터가 아닌 변경된 데이터만을 추출 및 적재하는 방식
  • 목적: 효율적인 데이터 적재, 실시간 분석, 자원 절약
  • 핵심 기술: CDC (Change Data Capture)
    • 변경 감지: Insert, Update, Delete 이벤트 감지
    • 변경 추출: 트랜잭션 로그, 타임스탬프, 트리거 기반
    • 변경 전파: 변경된 데이터만 대상 시스템에 반영

✅ 2. 실습 기본 구성

  • 입력: Blob - input 컨테이너
  • 출력: Blob - output 컨테이너
  • 핵심 파일들:
    • orders_initial.csv: 최초 전체 데이터
    • orders_incremental.csv: 증분 데이터 모음
    • watermark.txt: 이전 실행 시점 기록 (e.g., 1900-01-01T00:00:00Z)
    • incremental_data_*.csv: 날짜별로 업로드된 증분 파일들

✅ 전체 흐름

  1. 이전 실행 시각 조회 (watermark.txt)
  1. 현재 실행 시각 저장 → NewWatermarkValue = @utcnow()
  1. 조건 필터링: watermark < 파일 업로드 시각 < NewWatermarkValue 만족하는 데이터만 Copy
  1. 데이터 복사: 조건 만족하는 증분 파일을 대상(output)에 적재
  1. 워터마크 갱신: 현재 시각을 watermark.txt에 저장

✅ 3. 실습 준비

  • Blob 컨테이너 구성
    • input: 증분 및 초기 파일 업로드
    • output: 적재 결과 저장
  • 실습용 파일 준비
    • orders_initial.csv
    • orders_incremental.csv
    • orders_incremental_3rd.csv, 4th.csv, 5th.csv
    • watermark.txt: 1900-01-01T00:00:00Z 초기값 설정

✅ 4. 파이프라인 구성

✅ 구성요소

  1. Lookup: 이전 실행 워터마크 값 조회 (watermark.txt 첫 행)
  1. Set Variable: 현재 시각을 NewWatermarkValue 변수에 저장
    NewWatermarkValue = @utcnow()
  1. Filter 조건 적용 후 Copy: 아래 조건을 만족하는 파일만 적재
    watermark < 업로드 시각 < NewWatermarkValue
  1. Copy Activity: 조건을 만족하는 증분 CSV 복사
  1. 워터마크 파일 갱신: NewWatermarkValue를 다시 watermark.txt로 저장

✅ 5. 게시 및 실행 단계

✅ 초기 실행

  • orders_initial.csv → output 컨테이너에 적재
  • watermark: 1900-01-01T00:00:00Z

✅ 증분 실행 1

  • orders_incremental.csv 업로드
  • 조건 만족하는 데이터만 복사
  • watermark 갱신

✅ 증분 실행 2~3

  • 3rd, 4th, 5th 파일 순차 업로드 후 실행
  • 각각의 실행에서 watermark 조건에 맞는 데이터만 적재됨

✅ 6. 전체 흐름 요약

Blob - input
 └─ ForEach
     └─ Pipeline
         ├─ Lookup (이전 watermark 확인)
         ├─ Set Variable (현재 시간 저장)
         ├─ Copy (조건 만족 시 데이터 적재)
         └─ Copy (워터마크 갱신)
Blob - output

✅ 7. 마무리 및 활용

  • 장점: 데이터 처리 비용 최소화, 최신 데이터 유지, 빠른 분석 가능
  • 활용 예시:
    • 매출/주문 데이터 실시간 반영
    • 실시간 센서 데이터 적재
    • 정기적 보고용 데이터 자동 적재
  • 응용 가능:
    • SQL 기반 CDC 연계
    • Power BI 실시간 대시보드와 연동
