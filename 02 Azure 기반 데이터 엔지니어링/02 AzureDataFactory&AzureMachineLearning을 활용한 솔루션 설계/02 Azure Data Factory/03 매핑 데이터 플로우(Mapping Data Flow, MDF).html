매핑 데이터 플로우(Mapping Data Flow, MDF)

  • 코드 없이 시각적으로 ETL(데이터 추출, 변환, 적재) 변환을 설계할 수 있는 기능
  • ADF 내에서 GUI로 구성하고 Spark 엔진으로 실행
  • 특징
    • GUI 기반 데이터 변환 설계 (코딩 불필요)
    • 대용량 병렬 처리 (Spark 기반)
    • ADF 파이프라인 내 Activity로 사용 가능
  • 활용 예시
    • 원시 데이터 정제
    • 로그 분석 전처리
    • DWH 적재 전 변환
  • 주요 구성 요소
    구성 요소설명
    Source데이터 입력 (Blob, SQL 등)
    Transformation데이터 변환 로직 적용
    Sink데이터 저장 (Blob, SQL 등)
  • 주요 변환 기능
    기능설명예시
    Select컬럼 선택 및 이름 변경필요한 열만 추출
    Filter조건으로 행 필터링오류 로그만 추출
    Join다른 스트림과 조인사용자 정보 병합
    Aggregate그룹화 및 집계과목별 평균 계산
    Derived Column계산 컬럼 생성평균, 등급 파생
    Sort정렬 수행성적순 정렬
    Pivot열을 행으로 변환카테고리 분석
  • 흐름 제어 기능
    • Conditional Split: 조건 분기 (예: 나이별 분류)
    • Exists / Lookup: 외부 참조 존재 여부 판단

⚙️ MDF 실행 방식

  • 실행 흐름
    • ADF 파이프라인 내 Data Flow Activity로 호출
    • *Integration Runtime(IR)**에서 Spark 클러스터 자동 생성/종료
  • 디버그 모드
    • Sample 데이터 기반 결과 시각 확인
    • 실시간 컬럼 파생, 오류 점검 가능

🧪 실습 예시 흐름

  1. 데이터 준비
    • Kaggle: Student Performance in Exams
    • Blob Storage의 input, output 컨테이너 사용
  1. MDF 생성
    • Source 설정 → 파생 컬럼(평균, 등급) → Sink 저장
  1. 파이프라인 생성 및 실행
    • MDF를 포함한 파이프라인 구성 및 실행
  1. 디버깅 및 결과 확인
    • 실시간 결과 확인 후 배포 가능
