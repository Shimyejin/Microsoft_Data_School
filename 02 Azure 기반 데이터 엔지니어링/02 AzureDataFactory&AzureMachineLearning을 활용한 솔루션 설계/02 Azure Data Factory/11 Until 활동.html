Until 활동

  • “조건을 만족할 때까지 반복하는 루프”를 구현하는 ADF 파이프라인 활동
  • 특정 조건이 True가 될 때까지 계속 반복

⚙️ 구성 요소

요소설명
Expression반복 종료 조건 (@greater(variables('offset'), 1000) 등)
Activities반복 수행할 작업들 (예: 데이터 복사, 변수 증가 등)
Timeout반복 최대 시간
Retry실패 시 재시도 횟수

⚙️ 시나리오

시나리오설명
페이징 처리API 또는 쿼리 결과가 한 번에 다 안 나올 때, offset 기반 반복 조회
조건적 반복특정 작업이 성공할 때까지 재시도
대기 로직외부 시스템 준비 완료 여부를 반복 확인

🧪 실습 흐름 요약

  • 목표: offset을 10씩 증가시키며, 1000 이상이 될 때까지 반복
  • Set Variable → offset = 0
  • Until Activity
    • 조건: @greater(variables('offset'), 1000)
    • 내부 활동:
      • Add Variable (offset += 10)
      • (선택) 파일 복사, API 호출 등
[Set Variable: offset = 0]
        ↓
[Until (offset > 1000까지 반복)]
    └─ [Add Variable: offset += 10]
        [Copy Data (선택)]
