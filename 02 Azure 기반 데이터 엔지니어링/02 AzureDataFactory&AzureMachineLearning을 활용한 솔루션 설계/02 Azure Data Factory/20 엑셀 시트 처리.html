엑셀 시트 처리

✅ 1. 실습 개요 및 목적

  • 목적: Excel 파일의 여러 시트를 ADF(Azure Data Factory)를 통해 자동으로 순회하며 CSV로 추출하는 파이프라인 구성
  • 적용 시나리오: 복수 시트를 가진 업무 보고서, 지역/부서 단위 보고서를 자동 수집하고자 할 때 유용

✅ 2. 주요 실습 대상 파일

  • employees.xlsx: 일반적인 엑셀 파일
  • employees_sheets.xlsx: 복수 시트를 포함한 엑셀 파일 (예: 시트 0~3)

✅ 3. 실습 구성 흐름

💡 입력 파일

  • employees.xlsx
  • employees_sheets.xlsx

💡 출력 파일

  • employees.csv
  • employees_sheet_0.csv
  • employees_sheet_1.csv
  • employees_sheet_2.csv
  • employees_sheet_3.csv (실패 시 제외 가능)

💡 변수 설정

변수명설명초기값
countersheet index를 나타내는 변수0
isError오류 발생 여부false
tempCounter복사 직전 counter 백업없음

✅ 4. 반복 처리 로직 구성 (Until 반복문)

  • 반복 구조: Until 활동 사용 → isError == true 조건까지 반복
  1. tempCounter = counter + 1
  1. Copy Activity 실행
    • 원본: 특정 시트 (sheetIndex = counter)
    • 대상: employees_sheet_{counter}.csv
  1. 성공 시:
    • counter = tempCounter
  1. 실패 시:
    • isError = true
  1. 대기용 Dummy 활동 (Wait 등 사용)

✅ 5. 파이프라인 구성 순서

  1. Set Variable - tempCounter
  1. Copy Activity (엑셀 → CSV 변환, Sheet index 활용)
  1. Set Variable - counter
  1. Set Variable - isError (실패 시 true)
  1. Wait
이 전체가 Until 내부에 구성됨

✅ 6. 데이터세트 설정

  • 원본 데이터세트:
    • 파일 형식: Excel
    • 시트 이름 동적 지정: sheetName 파라미터 활용
  • 싱크 데이터세트:
    • 파일 형식: CSV
    • 동적 경로 지정: employees_sheet_@{variables('counter')}.csv

✅ 7. 게시 및 실행

  • 전체 파이프라인을 게시 후 실행하면, 시트 개수만큼 자동 순회하면서 CSV 생성
  • 실패 시점에서 반복 중단됨 (isError == true로 설정)

✅ 8. 실습 결과 예시

생성된 파일설명
employees.csv단일 시트 엑셀 복사 결과
employees_sheet_0.csv시트 0 복사 결과
employees_sheet_1.csv시트 1 복사 결과
employees_sheet_2.csv시트 2 복사 결과
employees_sheet_3.csv(복사 실패로 생략 가능)

✅ 9. 요약

  • 여러 시트를 가진 Excel 파일도 반복문(Until)과 변수 조합으로 순차적으로 복사 가능
  • 오류 발생을 조건으로 반복을 종료하여 유연한 데이터 처리 가능
  • 업무 자동화, 대시보드 데이터 수집에 유용
