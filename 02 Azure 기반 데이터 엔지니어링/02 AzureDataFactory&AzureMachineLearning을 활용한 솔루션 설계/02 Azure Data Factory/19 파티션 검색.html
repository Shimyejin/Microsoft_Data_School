파티션 검색

✅ 1. 파티션 검색이란?

  • 정의: 복사 활동(Copy Activity) 시 원본 경로에서 계층 구조를 자동 분석하여, 해당 폴더 이름을 열(Column)로 추가하는 기능.
  • 주요 목적: 파일에 존재하지 않는 메타데이터(예: 연도, 지역, 부서 등)를 컬럼으로 자동 보강.

✅ 2. 주요 장점

  1. 개발 생산성 향상: 복잡한 파싱 코드 없이 GUI로 설정만 하면 됨.
  1. 데이터 컨텍스트 추가: 시간, 지역, 카테고리 등의 추가 정보 제공.
  1. 로직 단순화: 이후 단계에서 파티션 컬럼으로 필터/그룹 조건 활용 가능.
  1. 시계열 데이터 처리 용이: 로그, IoT, 판매 데이터 등 연-월-일 폴더 구조 분석 가능.
  1. 증분 데이터 로드와 연계: 원하는 날짜/카테고리만 선택적으로 처리.
  1. 카테고리별 데이터 분리 처리: 지역, 국가, 부서 단위 분리 분석 가능.

✅ 3. 파티션 검색 활성화 방법

  • 체크박스로 on/off 설정 가능 (기본값: off)
  • Partition Root Path: 파티션 시작 경로 지정 → 하위 폴더들이 컬럼으로 자동 인식

✅ 4. 실습 구성 개요

  • 소스 데이터: ADLS에 저장된 sales와 employee 데이터
  • 경로 예시:
    • sales/year=2023/month=10/log.csv
    • employee/Department=Sales/Country=KR/employee.csv
  • 목표: 위 경로의 year, month, Department, Country 값을 컬럼으로 자동 추가

✅ 5. 실습 구성 흐름

  1. ADLS - raw-data
    • 원본 폴더 예: /sales/year=2023/month=10/log.csv
  1. Copy Activity
    • 파티션 검색 활성화
    • 예: sales/*/*.csv → year, month 열 추가됨
  1. ADLS - transformed-data
    • 컬럼 추가 후 저장 위치
  1. ForEach 활동
    • 반복 처리: 각 월/부서/국가별로 반복 처리
  1. Data Flow (데이터 플로우)
    • 파티션된 컬럼 필터링 및 집계
    • 예: Department, Country 별 직원 수 집계
  1. ADLS - output-data
    • 최종 결과 저장
    • 예: part1_result/monthly_sales_summary.csv, employee_result/final_employee_list.csv

✅ 6. 예시 데이터 경로와 자동 컬럼

경로자동 생성 열
/sales/year=2023/month=10/log.csvyear=2023, month=10
/Department=IT/Country=JP/employee.csvDepartment=IT, Country=JP

✅ 7. 실습 요약

  • 파티션 검색 기능을 통해 폴더 이름 기반 메타데이터를 데이터 컬럼으로 자동 추가
  • ADLS에 저장된 계층적 폴더 구조의 데이터를 더 쉽게 집계/필터링 가능
  • 복잡한 스크립트 없이 GUI 설정만으로도 강력한 데이터 보강 가능
