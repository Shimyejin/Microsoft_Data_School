Lookup & ForEach Activity

⚙️ Lookup Activity

  • 외부 데이터 소스(예: SQL, Blob, JSON 등)에서 데이터를 가져오는 활동
  • 주로 리스트 형태 데이터를 가져와 후속 작업의 입력값으로 사용
  • 기능
    • 테이블/파일에서 값 읽기
    • 읽은 값을 변수처럼 사용
    • ForEach나 다른 활동과 연동하여 동적인 파이프라인 설계 가능
  • 활용 예시
    • 처리할 파일 목록 조회
    • 테이블 리스트 가져오기
    • JSON 배열 읽기

⚙️ ForEach Activity

  • 배열(리스트) 형태의 값을 받아, 각 항목에 대해 반복 작업 수행
  • 기능
    • Lookup 결과(예: 파일 목록)를 받아 각 항목에 대해 반복 실행
    • 반복 방식: 병렬 또는 순차(직렬) 선택 가능
    • 반복 내에서는 복사, 로깅, 필터링 등 다양한 작업 구성 가능
  • 활용 예시
    • 여러 파일을 반복해서 Copy
    • 여러 테이블에 일괄 적재
    • 각 레코드에 대해 별도 처리 실행

🔁 Lookup → ForEach 전체 흐름

[Lookup]
  ↓ (리스트: wine.csv, titanic.csv, adult.csv)
[ForEach]
  → 항목 1 처리
  → 항목 2 처리
  → 항목 3 처리
Lookup이 리스트를 넘기면, ForEach가 리스트의 각 항목을 하나씩 꺼내 반복 처리
둘은 동적인 자동화 파이프라인의 핵심 구성

🧪 실습 흐름 요약

  • Lookup: SQL에서 테이블 목록 조회 or Blob에서 CSV 리스트 조회
  • ForEach: 각 파일에 대해 Copy Activity 실행
  • Sink: 각 파일을 대상 저장소에 저장
  • 파이프라인 내 주요 표현식
    표현의미
    @item()ForEach 반복 중 현재 항목
    @item().name항목 내 특정 속성 접근 (예: 파일 이름)
