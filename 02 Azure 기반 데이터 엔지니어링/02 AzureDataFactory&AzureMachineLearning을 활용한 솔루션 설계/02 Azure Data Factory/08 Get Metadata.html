Get Metadata

파일, 폴더, 테이블 등 데이터 소스의 메타데이터를 조회하는 활동

예: 파일의 존재 여부, 크기, 수정일, 컬럼 구조 등

  • 구성요소
    구성 요소설명
    Dataset연결된 데이터 소스 정보 (경로 포함)
    Field list조회할 항목들 (예: size, lastModified, childItems, structure)
    Filter확장자나 이름 패턴 필터링 (*.csv 등) 가능
  • 활동 시나리오
    시나리오설명
    파일 존재 여부 확인존재 여부에 따라 분기 처리(If Condition) 가능
    폴더 내 파일 목록 조회childItems 활용해 반복 작업 (ForEach 등)
    테이블 스키마 조회컬럼 목록 등 구조 확인 → 후속 매핑 흐름에서 사용
    수정일 기반 조건 처리lastModified 값으로 최신 여부 판단 가능
  • 장점
    • 조건 분기 자동화: 존재 유무에 따라 흐름 제어
    • 사전 검증: 복사/변환 전에 불필요 작업 방지
    • 재사용성: 모듈화하여 여러 파이프라인에 사용 가능

🧪 실습 구성 요약

  • 실습 1: 파일 메타데이터 조회
    • 대상: winequality-red.csv, winequality-white.csv
    • 확인 항목: 존재 여부, 최종 수정 시간
    • 결과에 따라 후속 처리 제어
  • 실습 2: 반복 구조 활용
    • childItems로 폴더 내 파일 목록 조회
    • ForEach + If Condition 활용하여
      • 이름이 red면 Copy Red
      • 이름이 white면 Copy White
# 전체 흐름

[Get Metadata]
     ↓
[ForEach (파일 목록)]
     ↓
[If Condition]
  ├── "red" → Copy Red
  └── "white" → Copy White
