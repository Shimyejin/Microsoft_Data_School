Fail 활동

✅ 1. Fail 활동(Fail Activity) 개요

  • 정의: 파이프라인 실행 중 특정 조건에서 의도적으로 실패 상태를 발생시켜 오류 처리 흐름을 유도할 수 있는 활동
  • 주요 특징:
    • 오류 메시지 및 코드 사용자 정의 가능
    • 의도적인 중단을 통해 분기 및 예외 흐름 테스트 가능
    • 논리적 조건 실패 시 강제 종료 가능
    • 필수 입력값 누락, 데이터 조건 미충족 시 활용 가능
  • 주요 활용 시나리오:
    • 특정 조건에서 오류 유도 및 메시지 전달
    • 디버깅이나 예외 흐름 테스트 용도
    • 입력 파일 유무, 데이터 유효성 조건 기반 분기 처리

✅ 2. 오류 메시지 및 코드 구성

  • 오류 메시지: 사용자가 정의한 메시지를 설정하여 로그나 디버깅에 활용
  • 오류 코드: 선택적으로 사용자 정의 코드 입력 가능 (예: ERR_FILE_NOT_FOUND_404)

✅ 3. 실습 1: 파일 존재 여부 기반 실패 유도

✅ 실습 구성도

Blob - input
 └─ ForEach
     └─ Pipeline
         ├─ Get Metadata (파일 존재 여부 확인)
         ├─ If Condition (True/False 분기)
         │   ├─ True: Copy Activity
         │   └─ False: Fail Activity (오류 유도)
         └─ Blob - output

✅ 구성 요소 설명

  • Get Metadata: 파일 존재 여부 확인
  • If Condition: 존재 여부 조건 판단
  • Fail Activity: 파일 없을 경우 오류 메시지 출력
  • Copy Activity: 파일이 있을 경우 정상 복사

✅ 실습 흐름 요약

  1. input/output 컨테이너 준비
  1. sales_data.csv 업로드
  1. Get Metadata 구성: 파일 존재 여부 확인
  1. If Condition 구성: 존재하면 Copy, 없으면 Fail
  1. 오류 메시지 예시: Required source file was not found
  1. 오류 코드 예시: ERR_FILE_NOT_FOUND_404

✅ 4. 실습 2: 레코드 유무 기반 실패 유도

✅ 실습 구성도

Blob - input
 └─ ForEach
     └─ Pipeline
         ├─ Lookup (레코드 로드)
         ├─ If Condition (레코드 수 확인)
         │   ├─ True: Copy Activity
         │   └─ False: Fail Activity (오류 유도)
         └─ Blob - output

✅ 구성 요소 설명

  • Lookup: sales_data.csv에서 데이터 로드
  • If Condition: @greater(length(activity('Lookup1').output.value), 0)
  • Fail Activity: 레코드 없을 경우 오류 유도
  • 오류 메시지: Source file contains no data records
  • 오류 코드: ERR_EMPTY_FILE_204

✅ 실습 흐름 요약

  1. input/output 컨테이너 구성
  1. sales_data.csv와 sales_data_empty.csv 준비
  1. Lookup으로 레코드 로드 → 개수 확인
  1. 레코드 없으면 Fail 처리, 있으면 Copy
  1. 예외 상황 디버깅 및 흐름 확인 용이

✅ 5. 정리 요약

  • Fail 활동은 예외 처리 흐름을 시각적으로 명확하게 구성할 수 있는 강력한 도구
  • 조건 기반 분기 처리에서 필수적으로 활용 가능
  • 사용자 정의 오류 메시지/코드를 통해 디버깅과 모니터링을 효과적으로 수행
  • 실습을 통해 파일 존재 여부, 레코드 존재 여부에 따라 실패 처리 흐름을 제어하는 방식 습득
