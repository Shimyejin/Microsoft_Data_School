통합 런타임 (Integration Runtime, IR)

Azure Data Factory(ADF)에서 데이터 이동, 변환, 실행 등 모든 작업을 처리하는 컴퓨팅 리소스

즉, ADF의 실행 엔진!

Azure Data Factory에서 “누가 실행할 것인가”를 결정하는 핵심 실행 엔진

데이터 위치에 따라 Azure IR, SHIR, SSIS IR 중 적절한 것을 선택

⚙️ IR이 수행하는 기능

기능설명
활동 실행Copy Activity, 외부 작업 호출 등
데이터 이동온프레미스 ↔ 클라우드 간 안전한 복사
데이터 흐름 실행Mapping Data Flow 수행 (Azure IR 전용)

⚙️ IR 유형 3가지

유형설명설치 필요예시
Azure IR클라우드 간 복사 및 MDF 실행❌ 없음Blob → SQL 변환
Self-hosted IR (SHIR)온프레미스 또는 VNet 자원 연결✅ 필요사내 DB ↔ Azure
Azure-SSIS IRSSIS 패키지 실행용✅ 필요SSIS 이관
📌 선택 기준: 데이터 위치, 네트워크 환경, SSIS 사용 여부

🖥 SHIR (Self-hosted IR)

  • 언제 필요한가?
    • 온프레미스 DB 접근 (예: Oracle, MySQL)
    • 사설 네트워크(VNet) 내부 연결
    • 특수 커넥터 사용 시
# 구성 흐름

[Blob Storage] → [SHIR] → [SQL Server]
    (원본)     (변환·중계)   (싱크)
  • 설치 환경 예시
    • Azure Virtual Network + Subnet
    • SHIR용 VM + SQL Server용 VM 생성
    • SHIR 설치 후 ADF와 연결
