Azure Functions 실습

✅ 1. 실습 개요

  • 실습 목표

    Python과 VS Code를 이용하여 Azure Functions 앱을 로컬 및 클라우드 환경에서 직접 구축하고 배포 및 테스트하는 전체 과정을 실습한다.

  • 주요 단계
    1. VS Code를 이용해 Functions 프로젝트 생성
    1. 로컬 환경에서 함수 테스트
    1. Azure에 함수 앱 생성
    1. 로컬 코드를 Azure에 배포
    1. 배포된 함수 테스트
    1. 리소스 정리

✅ 2. 로컬 Azure Functions 프로젝트 생성

  1. VS Code 실행 후 F1 키 입력 → 명령 팔레트 열기
  1. 명령어 입력: Azure Functions: Create New Project
  1. 폴더 생성 및 선택 (예: azfunc-demo)
  1. 설정값 입력:
    • 언어: Python
    • 모델: Model V2
    • Python 인터프리터: Skip virtual environment
    • 템플릿: HTTP Trigger
    • 함수 이름: http_trigger
    • 권한 수준: Anonymous
  1. “Open in current window” 클릭하여 프로젝트 열기

✅ 3. AzureWebJobsStorage 설정 변경

local.settings.json 파일에서 다음과 같이 수정

{
  "IsEncrypted": false,
  "Values": {
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "FUNCTIONS_WORKER_RUNTIME": "python"
  }
}

✅ 4. Azurite 에뮬레이터 실행

  1. VS Code에서 F1 → Azurite: Start 명령 실행
  1. 우측 하단에 Azurite 실행 상태 확인

✅ 5. 로컬에서 Azure Functions 실행

  1. F5 키 또는 “실행 및 디버깅” 아이콘 클릭
  1. 터미널에서 로컬 서버 구동 확인
  1. 출력 예시:
    http://localhost:7071/api/http_trigger

✅ 6. VS Code에서 함수 테스트 (Azure 확장 기능 활용)

  1. 좌측 메뉴에서 Azure 아이콘 클릭
  1. Local Project > Functions 하위의 http_trigger에서 마우스 오른쪽 클릭
  1. Execute Function Now 클릭
  1. 요청 본문에 아래 입력:
    {
  "name": "Azure"
}
  1. 하단 출력창에서 실행 결과 확인

✅ 7. 웹 브라우저에서 함수 테스트

  1. 웹 브라우저 주소창에 입력:
    http://localhost:7071/api/http_trigger?name=azure
  1. 출력 메시지 확인:
    Hello, azure.

✅ 8. Azure 로그인 및 클라우드 환경 준비

  1. VS Code 좌측 Azure 아이콘 클릭
  1. Sign in to Azure 클릭 → 브라우저에서 로그인
  1. 구독 활성화 여부 확인

✅ 9. Azure에 Function App 생성

  1. F1 → Azure Functions: Create Function App in Azure 입력
  1. 설정값 입력:
    • 앱 이름: 고유한 이름 (예: el31-unique-az-fnc)
    • 런타임: Python 3.11
    • 리전: East US

✅ 10. 로컬 함수 앱을 Azure에 배포

  1. F1 → Azure Functions: Deploy to Function App 입력
  1. 이전 단계에서 만든 함수 앱 선택
  1. 배포 상태 메시지 확인 후 완료 여부 체크

✅ 11. 배포한 함수 앱 테스트 (Azure 상에서)

  1. F1 → Azure Functions: Execute Function Now 입력
  1. 배포한 함수 앱 → http_trigger 함수 선택
  1. 요청 본문 입력:
    {
  "name": "Azure"
}
  1. 결과 응답 확인

✅ 12. 불필요한 리소스 삭제

  1. Azure Portal 접속
  1. 좌측 탐색창에서 리소스 그룹 클릭
  1. 실습에서 생성한 리소스 그룹 이름 검색 (예: el31unique)
  1. 리소스 그룹 선택 → 삭제 버튼 클릭
  1. 리소스 그룹 이름 입력 → 최종 삭제

✅ 13. 실습 요약

  • Azure Functions를 VS Code에서 로컬 생성 → 테스트 → 클라우드 배포 → 원격 테스트까지 전 과정을 경험
  • Azurite로 로컬 환경에서 에뮬레이션 가능
  • 실시간으로 함수의 입력/출력을 확인하고 수정 가능
  • 최종적으로 Azure Portal에서 리소스를 관리하며 정리까지 수행
