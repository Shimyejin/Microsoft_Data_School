Azure Event Hubs

✅ 1. Azure Event Hubs란?

  • Azure Event Hubs는 확장성 높은 실시간 데이터 스트리밍 플랫폼이자 이벤트 수집 서비스로, 다양한 소스에서 발생하는 대량의 데이터를 실시간으로 수집하고 처리할 수 있음
  • 주요 특징:
    • 실시간 대량 데이터 수집 및 처리
    • 다양한 소스 (IoT 센서, 웹, 앱 등) 연동 가능
    • 실시간 분석, 대시보드 구축, 트랜잭션 처리 등 가능
    • Apache Kafka 호환으로 손쉬운 마이그레이션 가능

✅ 2. Azure Event Hubs 아키텍처

구성 요소설명
이벤트 생산자 (Producers)데이터를 생성하여 Event Hub로 전송하는 주체 (예: IoT 센서)
이벤트 허브 (Event Hub)생산자로부터 이벤트 수신 → 일시 저장 및 관리
이벤트 소비자 (Consumers)Event Hub에서 데이터를 읽어와 처리하는 주체 (예: Stream Analytics)

✅ 3. Kafka 호환 기능

  • Kafka는 대용량 실시간 데이터 피드를 처리할 수 있는 오픈 소스 스트리밍 플랫폼
  • Event Hubs는 Kafka 프로토콜 완벽 지원
  • 기존 Kafka 코드를 수정하지 않고도 Event Hubs로 마이그레이션 가능
  • Kafka 대신 Event Hubs 사용 시 이점:
    • 인프라 관리 부담 감소
    • Azure PaaS 기반으로 자동 확장 및 높은 가용성 제공

✅ 4. 스키마 레지스트리 기능

  • 스키마: 데이터 구조/형식을 정의하는 청사진 (예: JSON 스키마)
{
  "type": "record",
  "name": "SensorReading",
  "fields": [
    {"name": "deviceId", "type": "string"},
    {"name": "temperature", "type": "float"},
    {"name": "humidity", "type": "float"},
    {"name": "timestamp", "type": "long"}
  ]
}
  • 스키마 레지스트리 필요 이유:
    • 생산자와 소비자 간 스키마 불일치 방지
    • 데이터 오류 방지 및 품질 보장
  • Azure Schema Registry 주요 기능:
    1. 중앙 저장소에서 스키마 저장 및 버전 관리
    1. 생산자 데이터 자동 검증
    1. 소비자가 최신 스키마로 데이터 처리 가능

✅ 5. 활용 분야 및 사례

  • 실시간 대시보드 (예: 생산라인 모니터링, IoT 센서)
  • 이상 감지 시스템 (예: 보안, 금융 거래)
  • 개인 맞춤 서비스 제공 (예: 사용자 행동 분석)
  • 핵 사용 감지 (예: 온라인 게임 부정행위 탐지)

✅ 6. 실전 시나리오: 스마트 팩토리 IoT 데이터 수집

  1. IoT 센서 설치: 생산 설비의 상태, 온도, 진동 등 실시간 수집
  1. Event Hubs로 데이터 수집: MQTT, AMQP 등의 프로토콜 사용
  1. Azure Functions와 연동: Event Hubs 트리거로 실시간 분석 수행
  1. 분석 결과 활용:
    • 실시간 대시보드 구축
    • 이상 감지 및 알림 시스템
    • 생산 효율성 개선

✅ 7. Azure Portal에서 Event Hub 생성 절차

  1. 리소스 그룹 생성
    • https://portal.azure.com → 리소스 그룹 → + 만들기
    • 예: el31-solar-hubs-rg
  1. Event Hubs 네임스페이스 생성
    • Event Hubs → + 만들기
    • 예: el31-solar-hub-ns, 위치: East US
  1. Event Hub 생성
    • 네임스페이스 선택 후 + 이벤트 허브
    • 예: el31_solar_hub, 파티션 수: 1개, 보존 시간: 1시간

✅ 8. 실습: Azure Functions와 Event Hubs 연동

  1. Git 설치 후 프로젝트 클론
    git clone https://github.com/IDKNWHORU/azure-functions-eventhubs
cd azure-functions-eventhubs
code .
  1. local.settings.json 설정
    {
  "IsEncrypted": false,
  "Values": {
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "FUNCTIONS_WORKER_RUNTIME": "python",
    "SolarEventHubName": "el31_solar_hub",
    "SolarEventHubConnectionString": "<복사한 연결 문자열>"
  }
}
  1. Event Hub 연결 문자열 확인 방법
    • Azure Portal → Event Hub 네임스페이스 → 설정 → 공유 엑세스 정책
    • RootManageSharedAccessKey → Primary connection string 복사 후 설정 파일에 삽입
  1. Azure Function 실행 방법
    • VS Code에서 F5 실행
    • 함수 eventhub_trigger에서 마우스 우클릭 → Execute Function Now…
    • 요청 본문: {"name": "Solar Energy"} 입력 후 실행
  1. Event Hub 전송 확인
    • Azure Portal → Event Hub → Data Explorer → 이벤트 보기
    • 메시지 본문에 "Solar Energy" 확인 가능

✅ 9. 요약 정리

  • Azure Event Hubs는 Kafka 호환성과 스키마 레지스트리를 제공하는 확장성 높은 실시간 데이터 스트리밍 서비스
  • 다양한 데이터 소스를 수집하여 실시간 분석과 서비스에 활용 가능
  • Azure Functions와의 연동을 통해 손쉽게 실시간 파이프라인 구축 가능
  • 실습을 통해 Git, VS Code, Azure Portal을 이용한 end-to-end 파이프라인 구현 가능
